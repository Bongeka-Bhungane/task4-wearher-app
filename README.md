# Weather Application

A comprehensive React-based weather application built with TypeScript, Vite, and Tailwind CSS. This app provides real-time weather information, location-based forecasting, weather alerts, and customizable settings.

## Features

### 🌤️ Real-time Weather Information
- Current weather conditions (temperature, humidity, wind speed, pressure, visibility)
- Hourly and daily weather forecasts
- Toggle between hourly and daily forecast views
- Beautiful weather icons and descriptions

### 📍 Location-Based Forecasting
- Automatic location detection with user permission
- Search functionality for any location worldwide
- Current location weather display
- Multiple location support

### 💾 Multiple Locations
- Save and manage multiple locations
- Quick switching between saved locations
- Persistent location storage
- Easy location removal

### 🎨 Customization
- Light and dark theme support
- Temperature unit switching (Celsius/Fahrenheit)
- Responsive design for all screen sizes
- Beautiful gradient backgrounds

### ⚡ Performance
- Fast loading with optimized components
- Smooth animations and transitions
- Efficient state management
- Responsive design (320px, 480px, 768px, 1024px, 1200px)

### 🔒 Privacy & Security
- No personal data stored on external servers
- Local storage only for user preferences
- Secure location handling
- Privacy-focused design

## Installation

### Prerequisites
- Node.js (version 18 or higher)
- npm or yarn package manager

### Setup Instructions

1. **Clone or download the project**
   ```bash
   git clone <https://github.com/Bongeka-Bhungane/task4-wearher-app>
   cd <wearher-app>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

## Usage

### Getting Started
1. **Allow Location Access**: When prompted, allow the app to access your location for current weather data
2. **Search Locations**: Use the search tab to find weather for any city worldwide
3. **Save Locations**: Save searched locations for quick access
4. **Customize Settings**: Switch between themes and temperature units in the settings tab
5. **View Forecasts**: Toggle between hourly and daily forecast views
6. **Monitor Alerts**: Enable notifications to receive severe weather alerts
